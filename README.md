## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/Parizoda-max/JavaScript-Learn.git
```

Go to the project folder:

```bash
cd JavaScript-Learn
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
